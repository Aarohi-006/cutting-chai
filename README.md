# Cutting Chai (3-D store)

A 3-D diorama of **Cutting Chai**, a fictional Mumbai-style chai stall in Jackson Heights, Queens.
Part of my Core 3 final branding project, *Cutting Chai*: half a glass, full conversation (एक कटिंग, दो बातें).

**Live:** https://aarohi-006.github.io/cutting-chai/

## What it is
- Built with [three.js](https://threejs.org) (r128)
- `index.html` = structure · `style.css` = look (brand tokens at the top) · `script.js` = the 3-D build
- Shop sign, awning, chai station, menu board and posters are drawn with the brand's type (Rozha One + Playfair Display) and palette (Rani Pink, Haldi Yellow, Chai Brown, Doodh Cream)
- Six camera views: street, window, counter, standing, retail, top
- Drag to rotate, scroll to zoom

## Run it
Open `index.html` in a browser (needs internet for three.js and Google Fonts).
